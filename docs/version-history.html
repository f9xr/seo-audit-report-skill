Version History

Changelog for SEO CodeBase Auditor SKILL.

v5.0 Current

Latest release with competitive gap analysis enhancements.

24 pillars  |  22 prompt templates

New in v5.0

  • Staging/Dev Subdomain Detection (Pillar 2) — Publicly accessible staging environments, leaked canonical/OG references, auth-gating recommendations
  • URL Slug Quality Evaluation (Pillar 4) — Keyword inclusion, stop word bloat, meaningfulness, length assessment
  • Sitemap URL Inventory Analysis (Pillar 9) — URL categorization by type, low-value inflation detection, sitemap cleanup
  • OG/Twitter Quality Review (Pillar 10) — Beyond presence checks: og:image dimensions, og:title divergence, twitter:card appropriateness, og:description quality
  • Two-Layer Trust Page Verification (Pillar 16) — Exists + Reachable verification, automated contact pathway detection
  • Keyword Placement Scoring (Pillar 1) — Five highest-signal zones: title, H1, URL slug, first paragraph, H2
  • Mandatory Evidence/Impact/Fix Format — Three-part finding structure enforced across all pillars
  • Report Detail Writing Rules — 6 detailed writing rules added
  • 5 New Prompt Templates: E-E-A-T Deep Audit, Staging Environment Audit, URL Slug & Keyword Placement Audit, Social SEO Quality Audit, Sitemap URL Inventory Audit

v4.2 Stable

New in v4.2

  • IndexNow Protocol — Setup and submission guidance in Pillar 9: key file hosting, HTTP POST to api.indexnow.org, response code reference, curl test command
  • Missing Title Tag Detection — Fix workflow with step-by-step remediation
  • Short Title Tag Remediation — Under 40 character flagging with rewrite guidance
  • Meta Description A/B Testing — Framework for testing variant descriptions
  • Bing Webmaster Tools Monitoring — CTR tracking recommendation
  • Quarterly Review Cycle — Meta description freshness guidance
  • 2 New Prompt Templates: Title & Meta Description Optimization, IndexNow Setup
  • Conclusion Section — F9XR Team attribution added

v4.1

New in v4.1

  • Extended from 23 to 24 pillars — Video & YouTube SEO added
  • Video & YouTube SEO Pillar — VideoObject schema, YouTube embed best practices, transcripts, thumbnails, video sitemaps, channel signals, accessibility, rich result eligibility, performance impact
  • Voice Search Optimization — Explicit sub-discipline within Pillar 18 (AI/SGE/LLM)
  • Keyword Density Calculation — Methodology added to Pillar 7
  • Report Customization — Attribution line support, emoji heading option, fix-type grouping option
  • 2 New Prompt Templates
  • Expanded Output Blueprint — Revenue Impact, Time to Impact, Business Value columns

v4.0

New in v4.0

  • Extended from 22 to 23 pillars — Competitor SEO Analysis added
  • Enterprise Task-Force Persona — 14 specialized roles defined
  • Crawl Orchestration & Discovery Phase — Detailed workspace exploration
  • Competitor SEO Analysis Pillar — 3-4 competitor comparison across 12 dimensions
  • Advanced Semantic SEO Depth — Entity salience, passage optimization, topic clustering, co-occurrence, taxonomy quality, information gain, NLP readiness
  • Filled Remaining Gaps: FCP/TTFB in CWV, mobile/desktop split, redirect loops, soft 404s, broken external links, parameterized URLs, infinite crawl traps, crawl budget, CDN/compression/caching/server-response, duplicate pages/metadata, CTR/SERP optimization, structured content layout, table optimization, Organization/Service/Person schema, E-E-A-T Experience signals, reputation audit, content credibility
  • 4 New Prompt Templates
  • Expanded Output Blueprint — Revenue/Traffic Opportunity sections, CSV export, Implementation Guidance, Fix Type fields, Medium-Term and Long-Term sections
