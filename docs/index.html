SEO CodeBase Auditor SKILL

Enterprise-grade, evidence-driven SEO auditing for static code repositories. 24 pillars, one file, production-ready fix blocks.

Built by F9XR Team — Website development, redesign, local SEO & digital presence solutions.

What Is This?

SEO CodeBase Auditor is an AI-powered skill that performs deep SEO audits on static codebases. Drop SKILL.md into any project, run a prompt in your AI coding assistant, and receive a comprehensive audit report with exact code fixes — no manual checks, no guesswork.

Quick Example

@SKILL.md Run a comprehensive full-stack SEO audit across all files in this workspace.

This generates:

  • seo_audit_report.md — Full audit with fix blocks
  • seo_audit_report.csv — Priority matrix for spreadsheets

Key Features

  • 24 SEO Pillars — Technical SEO, On-Page, Performance (CWV), Semantic SEO, E-E-A-T, Competitor Analysis, Video/YouTube SEO, Voice Search, IndexNow, and more
  • Context-Aware — Portfolio sites, e-commerce stores, SaaS landing pages, and local businesses each receive tailored audits
  • Production-Ready Fixes — Every finding includes the exact code block you can paste and deploy
  • 5-Pass Audit Workflow — Discover, Analyze, Prioritize, Report, Critique
  • Priority Fix Matrix — Capped at 20 items, sorted by severity and traffic impact
  • CSV Export — Spreadsheet-ready issue tracker included alongside the markdown report
  • AI-Native — Works with Cursor, Copilot, Claude, ChatGPT, and any AI coding assistant
